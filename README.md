# DeltaForce

> 基于 Unity + Mirror 联网的 2D 俯视角战术射击游戏 —— 融合撤离射击装备系统与多人对战玩法

## 🎮 项目简介

DeltaForce 是一款受《逃离塔科夫》《三角洲行动》启发的 **2D 俯视角多人战术射击游戏**。游戏采用客户端-服务器（Host/Listen Server）网络模型，玩家可以创建主机房间或加入他人房间，在 2D 地图中搜刮武器弹药、管理装备背包、并与敌对玩家展开战术对抗。

核心特色是 **写实的弹药穿透与护甲防护系统**：不同弹药拥有独立的穿透等级，护甲具备防护等级和耐久值，两者之间的等级差决定最终伤害效果——穿透、半穿、钝伤，各有不同表现。

## 🧠 游戏系统详解

### 1. 武器系统

- 玩家拥有 **2 个武器槽**，按 `1`/`2` 切换
- 每把武器由 `WeaponData` 定义，包含：武器名、弹药类型、弹匣容量、穿透等级、射速、子弹初速、换弹时间
- 当前仅实装 **M4A1 突击步枪**（30 发弹匣，穿透等级 1，射速 0.1s，换弹 1.5s）
- 弹匣打空后自动触发换弹，也可按 `R` 手动换弹
- 射击时在服务端实例化子弹，施加物理力，使用 Continuous 碰撞检测防止高速隧穿

### 2. 穿透与伤害系统

伤害计算基于 **子弹穿透等级** 与 **护甲防护等级** 的差值：

| 差值 (子弹 - 护甲) | 伤害 | 护甲消耗 | 效果描述 |
|:---:|:---:|:---:|------|
| ≥ +2 | **35** | 15 | 完全穿透 — 子弹轻易击穿护甲 |
| +1 | **25** | 10 | 穿透 — 子弹击穿护甲 |
| 0 | **20** | 10 | 半穿透 — 部分被护甲吸收 |
| -1 | **15** | 10 | 未穿透 — 大部分被护甲挡住 |
| ≤ -2 | **10** | 10 | 钝伤 — 子弹无法击穿，仅受冲击伤 |

- 护甲耐久值归零后，防护等级重置为 0，后续攻击全部按完全穿透计算
- 玩家 HP = 100，死亡后 3 秒自动重生

### 3. 弹药系统

- 弹药按口径分类（当前仅 **5.56×45mm** 系列）
- 同一口径下有 **5 个穿透等级**：RRLP(L1) → FMJ(L2) → M855(L3) → M855A1(L4) → M995(L5)
- 每格弹药 60 发，换弹时从背包消耗
- **消耗优先级**：胸挂 → 背包
- 换弹时自动选取剩余弹药中**穿透等级最高**的弹药

### 4. 背包与装备系统

| 槽位类型 | 数量 | 可放入物品 |
|------|:---:|------|
| 头盔 | 1 | Helmet |
| 护甲 | 1 | Armor |
| 武器 | 2 | Weapon |
| 胸挂 | 5 | Ammo、Item |
| 背包 | 5 | Ammo、Item、MedKit |

**物品类型：**
- **Helmet** — 未实装
- **Armor** — 提供防护等级和耐久值
- **Weapon** — 武器配置（M4A1）
- **Ammo** — 弹药（5 种穿透等级）
- **Item** — 变卖物（如 CPU），撤离后获得收益
- **MedKit** — 医疗包，右键使用回复血量，有耐久次数

**同步机制：** 背包数据在服务端以 JSON 字符串存储，通过 Mirror 的 `SyncVar<string>` 同步到客户端，确保服务端权威。

### 5. 物品生成

- 地图上放置 `ItemSpawner` 脚本
- 可配置为固定物品或随机物品
- 游戏开始时，服务端从 `ItemDatabase` 中随机选取物品，实例化并同步到所有客户端

### 网络架构

```
┌──────────────┐          ┌──────────────┐
│   Client A   │◄────────►│   Host/Server│
│  (玩家操作)   │  Mirror  │  (游戏逻辑)   │
│              │  Cmd/Rpc │              │
└──────────────┘          └──────┬───────┘
                                 │
                        ┌────────▼───────┐
                        │   Client B     │
                        │  (另一玩家)     │
                        └────────────────┘
```

- **联网模型：** Mirror Listen Server（主机即服务端）
- **同步方式：** `[Command]` 客户端→服务端，`[ClientRpc]` 服务端→客户端
- **SyncVar：** 生命值、护甲耐久、背包 JSON、弹匣弹药量
- **传输层：** 支持 KCP / Telepathy，端口可配置（通过 `PortTransport` 接口）
- **跨场景：** 通过静态 `NetworkConfig` 类传递 Host/Client 配置

## 🚀 快速开始

### 环境要求

- **Unity 编辑器：** 团结引擎 (Tuanjie) 或 Unity 2022.3+
- **.NET：** .NET Standard 2.1
- **操作系统：** Windows / macOS

### 本地单人测试

1. 用 Unity 打开项目
2. 打开 `Assets/Scenes/MainMenu.scene`
3. 点击播放 ▶️
4. 在菜单中点击 **Host** 按钮
5. 进入 GameMap 后即可开始游戏

### 本地多人测试（使用 ParrelSync）

1. 先在 Unity 中打开项目
2. 通过 **ParrelSync → Clones Manager** 创建一个克隆
3. 打开克隆的 Unity 编辑器
4. 主编辑器点击 **Host** 启动主机
5. 克隆编辑器点击 **Client** → **Join** 加入主机
6. 两个窗口即代表两个玩家，可以进行联机测试

### 局域网多人测试

1. 一台电脑启动 Unity，点击 **Host**
2. 另一台电脑启动 Unity，输入主机的局域网 IP 地址
3. 点击 **Client** → **Join** 加入
